## 動かし方（ローカル）

```bash
bash tools/localdb/start.sh                 # ローカルDB（54329）。初期アカウントは tools/localdb/README.md
pnpm --dir apps/table-server start          # 対局サーバー（8787）
pnpm --dir apps/web dev                     # 画面（3100）
```

- http://localhost:3100/ … ホーム（未ログインでも CPU 対局ができる）
- http://localhost:3100/dev/fx … 演出と和了画面の見本
- http://localhost:3100/dev/scene … 3Dの卓だけ

検証スクリプト（`tools/e2e`、実際の Chrome を動かす）:
`node play.mjs`（CPU戦を終局まで）／`node club.mjs`（クラブ卓4人→精算）／`node record.mjs`（マウス操作で通しプレイを録画）／`node fx.mjs`（演出の見本を録画）
